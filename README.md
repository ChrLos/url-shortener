# NanosURL
A simple and straightforward URL shortener

## Demo
https://nanosurl.vercel.app/

## Additional Features

Additional features implemented beyond the original tutorial scope:

- **Custom URL alias**: Have a custom URL alias
- **Alias duplicate check**: Display a simple error if the alias is a duplicate
- **Private view**: Everyone have their own personal view of the shortened URL list using cookies as identifier
- **Delete shortened links**: Ability to delete shortened URL from the list and the database

## Tech Stack
- Node.js
- Express
- MongoDB
- EJS

## Running Locally
```bash
git clone https://github.com/ChrLos/url-shortener.git
npm install
npm run devStart
```
